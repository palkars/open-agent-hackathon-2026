ResearchOS

A question needs memory and evidence.

The conclusion has to say whether that evidence supports the claim.

What it does

One question. Four panes. One assessment.

  • SUPPORTED The relevant evidence agrees, and none of it denies the question.
  • CONTRADICTED The relevant evidence denies the question, and none of it agrees.
  • MIXED Some evidence agrees and some denies it.
  • INSUFFICIENT No supplied evidence is about the question.

One warm run

Memory, then evidence, then Nemotron.

H-MEM recall Markovian, at most 3 chunks Zetaris rows Nemotron through Nightshift Contradiction check Store the finding

H-MEM text is injected into the first chunk. Later chunks carry only what is still open.

One result

Can a Lattice Ballot collect anonymous votes without a tallying authority?

  • Zetaris loads P232 and P233.
  • Both papers say yes, and both experiments passed.
  • The assessment should be SUPPORTED.

What stays local

The key never enters this repo.

Papers H-MEM Markovian Nightshift runtime

Papers, H-MEM, and Markovian stay on the machine. The NVIDIA key stays in Nightshift. The only outbound model call is the local Nightshift runtime.

npx tsx research-os/test-llm-reasoner.ts
